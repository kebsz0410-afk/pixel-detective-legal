04AI 심문 데이터 처리

이용자가 용의자에게 질문하면 앱은 현재 질문과 답변 생성에 필요한 대화 맥락을 Supabase Edge Function으로 전송합니다. Edge Function은 사건·용의자 접근 권한과 질문 횟수, 시간당 제한 및 비용 한도를 확인한 뒤 Anthropic API로 요청을 직접 전달합니다. 생성된 답변은 같은 경로로 앱에 반환됩니다.

성공한 질문과 답변은 대화 이어보기, 질문 횟수 확인, 프롬프트 개선과 스포일러 유출·부적절한 답변·캐릭터 이탈 점검을 위해 일반 사용량 로그와 분리해 계정 삭제 시까지 저장합니다. 실패한 요청의 질문·답변 원문은 서버에 저장하지 않습니다. 대화 원문은 본인 계정과 운영상 필요한 최소 인원만 접근할 수 있습니다.

화면에 표시되는 대화는 서버의 본인 계정 기록에서 복원합니다. 다음 답변을 만들 때는 최근 대화 중 필요한 범위만 Anthropic API 요청에 포함됩니다.

Anthropic API에는 질문과 답변 생성에 필요한 사건 설정 및 대화 맥락이 전송됩니다. 계정의 이메일과 닉네임을 답변 생성에 사용할 필요가 없으므로 원칙적으로 전송하지 않지만, 이용자가 질문 본문에 직접 적은 정보는 함께 전송될 수 있습니다.

AI 답변은 확률적으로 생성되어 사실과 다르거나 맥락에 맞지 않을 수 있습니다. 앱의 신고 기능으로 문제를 알려주시고, 개인을 식별할 수 있는 정보는 질문에 입력하지 마세요.

05보유 기간과 파기

계정·프로필·게임 진행·XP·운영 원장·신고 데이터는 계정이 유지되는 동안 보관하며, 계정 삭제가 완료되면 법령상 보존 의무나 분쟁 대응에 필요한 예외를 제외하고 삭제합니다. 게스트 계정도 같은 기준을 적용합니다.

  • 계정과 게임 데이터: 계정 삭제 시까지
  • 성공한 AI 질문·답변: 대화 이어보기와 품질·안전 개선을 위해 계정 삭제 시까지
  • AI 사용량 원장: 계정 삭제 시까지. 질문·답변 원문은 포함하지 않음
  • 서버(Edge Function) 실행 로그: 플랫폼 기본 보존 기간. 운영 코드가 남기는 로그에는 질문·답변·사건 프롬프트 원문을 포함하지 않음
  • AI 답변 신고 기록과 신고한 한 턴의 사본: 이용자가 신고를 명시적으로 제출한 경우만 별도 저장하며, 계정 삭제 또는 처리 목적 달성 시까지
  • 고객지원 이메일: 문의 처리 목적 달성 또는 이용자의 삭제 요청 시까지
  • 기기 설정: 앱 삭제 또는 기기 저장공간 초기화 시까지

Anthropic의 표준 API 정책에 따르면 API 입력과 출력은 수신 또는 생성 후 30일 이내 Anthropic 시스템에서 삭제됩니다. 다만 이용정책 집행, 법령 준수 또는 별도 계약이 적용되는 경우 기간이 달라질 수 있습니다. 최신 기준은 Anthropic의 API 보유 안내에서 확인할 수 있습니다.

전자적 파일은 복구하기 어렵도록 삭제하고, 관계형 데이터는 계정 식별자에 연결된 레코드를 함께 삭제합니다. 백업에 남은 사본은 백업 순환 주기에 따라 접근이 제한된 상태로 제거됩니다.
