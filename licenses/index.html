06NOTICE 생성과 출시 체크

legal-site의 scripts/generate-app-notice.mjs는 상위 앱 프로젝트의 package-lock.json과 설치된 node_modules를 읽어 프로덕션 런타임 패키지의 이름, 버전, 라이선스 메타데이터와 포함된 라이선스 문서를 public/NOTICE.txt로 생성합니다. 앱 프로젝트 파일은 수정하지 않습니다.

  1. 최종 출시 브랜치에서 의존성을 깨끗하게 설치합니다.
  2. NOTICE 생성 스크립트를 실행합니다.
  3. 라이선스 파일이 없거나 UNKNOWN으로 표시된 패키지를 수동 확인합니다.
  4. 앱 번들에 NOTICE를 포함하고 이 페이지의 버전 표를 최종 빌드와 대조합니다.
  5. 별도의 자산 원장에서 음원·이미지·폰트의 증빙과 표기 의무를 확인합니다.
