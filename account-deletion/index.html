삭제는 취소할 수 없습니다. 단순히 앱 사용을 멈추려는 경우에는 소셜 계정에서 로그아웃만 할 수 있으며, 로그아웃은 서버 데이터를 지우지 않습니다.

01삭제 전에 확인할 내용

데이터 삭제 또는 회원 탈퇴가 완료되면 계정과 수사 기록을 복구할 수 없습니다. 로그아웃, 앱 종료, 게스트의 시작 화면으로 돌아가기는 계정 삭제가 아닙니다.

삭제되는 주요 데이터: 로그인 계정, 프로필, 닉네임, 탐정 ID, 사건 진행, 수집한 단서와 소지품, 해결 등급, XP, 인벤토리, 보관 중인 AI 질문·답변, 질문 횟수, 신고와 운영 원장

삭제 뒤 새 게스트 계정을 만들거나 같은 Google·Apple 계정으로 다시 가입할 수는 있습니다. 다만 새 계정으로 처리되며 삭제한 기록은 돌아오지 않습니다.

02게스트 계정 삭제

현재 게스트 계정으로 앱에 들어갈 수 있다면 다음 경로가 가장 빠릅니다.

  1. 앱 하단의 마이페이지를 엽니다.
  2. 내 정보 영역으로 이동합니다.
  3. 데이터 삭제를 누릅니다.
  4. 경고문에서 삭제되는 범위를 확인합니다.
  5. 최종 확인을 완료하면 서버 계정과 연결된 데이터가 삭제되고 로그인 화면으로 이동합니다.

시작 화면으로 돌아가기는 데이터 삭제가 아니므로 기록이 유지됩니다. 삭제 요청이 실패하면 앱은 성공으로 표시하지 않으며 계정도 그대로 유지됩니다.

03Google·Apple 계정 탈퇴

소셜 계정으로 로그인할 수 있다면 다음 경로를 이용합니다.

  1. 앱 하단의 마이페이지를 엽니다.
  2. 내 정보 영역으로 이동합니다.
  3. 회원 탈퇴를 누릅니다.
  4. 삭제되는 데이터와 복구 불가 안내를 확인합니다.
  5. 최종 확인을 완료하면 탈퇴 처리 후 로그인 화면으로 이동합니다.

로그아웃은 계정과 서버 기록을 유지합니다. 회원 탈퇴는 서버 계정과 연결 데이터를 삭제하며, Apple 계정은 가능한 경우 서비스에 발급된 인증 권한 취소 절차도 함께 진행합니다. 인증 토큰이 만료되거나 남아 있지 않아 자동 취소할 수 없더라도 앱 계정과 데이터 삭제는 계속되며, 이 경우 Apple ID 설정에서 픽셀 탐정의 권한을 직접 해제하는 방법을 안내합니다. Google 계정은 픽셀 탐정과의 연결 정보가 해제됩니다. Google 또는 Apple 자체 계정은 삭제되지 않습니다.

04로그인할 수 없을 때 외부 삭제 요청

앱을 사용할 수 없거나 계정에 로그인할 수 없으면 pixeldetective.app@gmail.com으로 요청해 주세요. 이메일 제목은 계정 삭제 요청으로 적어주세요.

본인 계정을 찾고 다른 사람의 계정이 삭제되는 것을 막기 위해 다음 정보를 요청합니다.

  • 로그인 유형: 게스트, Google 또는 Apple
  • 탐정 ID 또는 닉네임을 알고 있다면 해당 정보
  • 소셜 로그인 계정이라면 서비스에 제공된 이메일
  • 대략적인 가입 시기, 마지막 플레이 사건과 마지막 이용 시기
  • 사용한 플랫폼과 기기 OS: iOS 또는 Android

비밀번호, 인증 코드, Google·Apple 토큰, 주민등록증 전체 사본은 보내지 마세요. 제공된 정보만으로 계정을 특정할 수 없으면 추가적인 최소 확인 절차를 안내할 수 있습니다.

05본인 확인과 처리 기한

앱에서 유효한 세션으로 직접 삭제하면 해당 세션을 본인 확인 수단으로 사용합니다. 이메일 요청은 소셜 로그인 이메일, 탐정 ID와 이용 기록 등 계정 소유자만 알 가능성이 높은 정보를 최소 범위에서 비교합니다.

운영 목표는 본인 확인이 끝난 날부터 7일 안에 삭제를 완료하는 것입니다. 계정을 찾기 어렵거나 보안 조사, 분쟁 또는 법령상 보존 의무가 있으면 시간이 더 필요할 수 있으며, 이 경우 사유와 예상 일정을 이메일로 안내합니다.

같은 삭제 요청이 네트워크 재시도나 중복 클릭으로 여러 번 도착하더라도 이미 삭제된 계정을 다시 처리해 오류를 만들거나 다른 계정을 삭제하지 않도록 안전하게 처리합니다.

06삭제 범위

데이터처리
Supabase Auth 계정과 세션계정을 삭제하고 기존 로그인 토큰을 더 이상 사용할 수 없게 합니다.
프로필·지갑·XP·인벤토리계정 식별자에 연결된 기록을 삭제합니다.
사건 진행·수집·해결 기록Case01~03 진행, 단서, 소지품, 등급과 잠금 기록을 삭제합니다.
AI 심문·사용량·신고계정에 보관 중인 성공 질문·답변, 원문 없는 횟수 원장, 운영 정보와 이용자가 명시적으로 제출한 신고 사본을 삭제합니다.
소셜 인증 연결서비스의 Google 연결을 해제하고, 가능한 경우 Apple 인증 권한 취소 절차를 진행합니다. 자동 취소가 불가능해도 앱 계정과 데이터 삭제는 계속합니다.
기기 설정사운드·BGM·햅틱은 계정과 무관한 기기 설정이라 남을 수 있습니다. 앱 삭제 또는 기기 저장공간 초기화로 직접 지울 수 있습니다.
고객지원 이메일계정 DB와 별도로 관리합니다. 문의 처리 목적이 끝나면 삭제하며, 분쟁이나 법적 보존 의무가 있는 경우 필요한 기간만 제한적으로 보관할 수 있습니다.

즉시 운영 시스템에서 제거된 정보가 암호화 백업에 남아 있다면 백업 순환 주기에 따라 삭제됩니다. 백업은 일반 서비스에서 복구하거나 이용자 계정을 되살리는 용도로 사용하지 않습니다.

07삭제 후 상태와 취소

삭제가 완료되면 이전 계정의 토큰으로 API에 접근할 수 없고, 같은 기기에서도 해당 이용자의 수사 기록이나 AI 대화를 표시하지 않습니다. 이는 다시 게임을 할 수 없다는 뜻이 아닙니다. 새 계정을 만들 수 있지만 이전 기록은 복구되지 않습니다.

삭제는 취소할 수 없습니다. 실수로 요청한 경우에도 서버 삭제가 완료된 뒤에는 되돌릴 수 없으므로 최종 확인 화면의 계정과 삭제 범위를 반드시 확인해 주세요.
