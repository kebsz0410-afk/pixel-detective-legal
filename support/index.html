01문의하기

앱 이용 중 해결되지 않는 문제가 있으면 아래 이메일로 문의해 주세요. 일반 문의는 접수 순서대로 확인하며, AI 답변 신고는 원칙적으로 24~72시간 안에 첫 검토를 진행합니다.

이메일: pixeldetective.app@gmail.com

운영자: 고은비 · 대한민국

문의를 보낼 때 다음 내용을 함께 적으면 확인이 빨라집니다.

  • 사용 중인 플랫폼: iOS 또는 Android
  • 앱 버전과 기기 OS 버전
  • 문제가 발생한 사건·장소·화면
  • 재현 순서와 표시된 오류 문구
  • 계정 확인이 필요하면 탐정 ID 또는 소셜 로그인 이메일

비밀번호, 일회용 인증 코드, Google·Apple 토큰, 주민등록번호와 결제정보는 보내지 마세요.

02로그인과 게스트 계정

어떤 로그인 방법을 사용할 수 있나요?

iOS와 Android에서 Google, Apple, 게스트 로그인을 제공합니다.

게스트도 기록이 서버에 저장되나요?

네. 게스트도 고유 계정이 만들어져 사건 진행, XP, 수집 기록과 AI 질문 횟수가 서버에 저장됩니다. 다만 소셜 계정에 연동하기 전에 앱을 삭제하거나 기기 데이터를 지우면 기존 게스트 계정에 다시 접근하기 어려울 수 있습니다.

시작 화면으로 돌아가면 기록이 삭제되나요?

아니요. 게스트의 시작 화면으로 돌아가기는 세션과 데이터를 유지합니다. 데이터를 지우려면 마이페이지의 데이터 삭제를 사용해야 합니다.

03게스트에서 소셜 계정으로 연동

게스트 기록을 Google 또는 Apple 계정에 연결할 수 있나요?

네. 아직 다른 게임 기록이 없는 소셜 계정이라면 현재 게스트 계정을 그대로 연동해 같은 수사 기록을 유지합니다.

이미 기록이 있는 소셜 계정이면 어떻게 되나요?

앱은 기존 소셜 계정 기록을 불러올지, 현재 게스트 기록을 유지할지 선택 안내를 표시합니다. 데이터가 자동으로 합쳐진다고 가정하지 마세요. 선택 전에 각 계정의 진행 상황을 확인해 주세요.

연동 후 다른 기기에서도 플레이할 수 있나요?

같은 소셜 계정으로 로그인하면 서버에 저장된 지원 범위의 기록을 불러옵니다. 기기에만 저장되는 사운드·BGM·햅틱 설정은 새 기기에서 다시 설정해야 합니다.

04AI 심문 3회 제한

3회는 사건 전체 기준인가요?

아닙니다. 첫 버전에서는 계정·사건·용의자 조합마다 성공한 질문을 최대 3회 보낼 수 있습니다. 예를 들어 같은 사건의 서로 다른 용의자는 각각 3회입니다.

네트워크 오류도 1회로 계산되나요?

서버에서 실패로 확정된 요청은 성공 횟수에 포함하지 않습니다. 처리 중 화면을 닫거나 통신이 끊긴 요청은 상태 확인에 시간이 걸릴 수 있으므로 잠시 후 다시 확인해 주세요.

질문과 답변은 저장되나요?

성공한 질문·답변은 같은 계정으로 다시 로그인했을 때 이어 볼 수 있도록 계정 삭제 시까지 저장됩니다. 실패한 요청의 원문은 서버에 저장하지 않습니다. 답변을 만들 때는 최근 대화 중 필요한 범위만 AI 프록시와 Anthropic API로 전달합니다. 개인정보나 민감한 정보는 질문에 넣지 마세요.

05다음 사건 공개

Case02 또는 Case03이 잠겨 있어요.

다음 사건은 직전 사건을 해결하면 서버 판정 후 즉시 열립니다. 네트워크가 끊겼다면 해결 기록과 공개 상태가 바로 갱신되지 않을 수 있으므로 연결을 확인하고 앱을 다시 열어 주세요.

광고를 보면 바로 열 수 있나요?

첫 버전에는 광고, 대기 시간 또는 잠금 해제 이용권이 없습니다. 직전 사건을 해결하면 별도 조건 없이 다음 사건이 바로 열립니다.

이전 사건을 해결했는데도 열리지 않아요.

네트워크 연결을 확인하고 앱을 완전히 종료한 뒤 다시 열어 주세요. 계속 잠겨 있으면 사건 번호, 해결 시각, 탐정 ID를 이메일로 보내 주세요.

06AI 답변 신고

용의자 답변 말풍선의 신고를 누르고 가장 가까운 항목을 선택한 뒤 신고하기를 누릅니다. 신고 대상 질문과 답변 사본, 사건·용의자 정보가 함께 저장되어 운영자가 확인합니다. 이 사본은 이용자가 신고를 명시적으로 제출한 턴에만 만들어지며 계정을 삭제하면 함께 삭제됩니다.

  • 모욕적이거나 불쾌한 내용
  • 성적 내용, 폭력, 혐오 또는 개인정보 노출
  • 범인·결말 스포일러 또는 캐릭터 설정 이탈
  • 명백히 잘못된 답변이나 기타 문제

신고 상태는 접수, 검토 중, 조치 완료 또는 기각으로 관리합니다. 긴급한 개인정보 노출, 현실의 위해 가능성 또는 반복 오류는 앱 신고와 함께 이메일로 알려주세요.

07로그아웃, 삭제와 복구

로그아웃하면 수사 기록이 사라지나요?

소셜 계정 로그아웃은 서버 기록을 삭제하지 않습니다. 같은 계정으로 다시 로그인하면 해당 계정의 기록을 불러옵니다. 다른 이용자가 로그인한 동안에는 이전 이용자의 대화나 캐시가 보이지 않도록 계정별로 분리합니다.

계정을 삭제한 뒤 복구할 수 있나요?

아니요. 데이터 삭제와 회원 탈퇴는 취소할 수 없습니다. 이후 같은 Google·Apple 계정으로 로그인하거나 새 게스트 계정을 만들 수 있지만 기존 진행은 돌아오지 않습니다.

삭제 버튼을 눌렀는데 실패했다고 나와요.

실패한 경우 데이터는 삭제되지 않았고 성공 화면도 표시하지 않습니다. 네트워크 연결을 확인한 뒤 다시 시도하고, 반복되면 외부 삭제 요청을 이용해 주세요.

08지원 기기와 화면

첫 버전은 App Store와 Google Play의 지원 OS 요건을 충족하는 iOS·Android 휴대폰 세로 모드에 맞춰 제공합니다. 기기를 돌려도 화면은 세로 방향을 유지할 수 있습니다. 웹 버전과 태블릿 전용 레이아웃은 첫 버전 지원 범위가 아닙니다.

작은 화면, 시스템 글자 확대 또는 화면 키보드 사용 중 버튼이 가려지면 최신 앱으로 업데이트하고 화면을 위아래로 스크롤해 주세요. 노노그램 보드 위에서는 게임 입력과 화면 이동이 충돌하지 않도록 보드 밖 영역을 사용합니다.

09기본 문제 해결

  1. Wi-Fi 또는 모바일 네트워크 연결을 확인합니다.
  2. App Store 또는 Google Play에서 최신 버전인지 확인합니다.
  3. 앱을 완전히 종료한 뒤 다시 실행합니다.
  4. 소셜 계정이라면 로그아웃 전에 로그인 수단과 이메일을 확인합니다.
  5. 계속 문제가 생기면 오류 문구와 재현 순서를 이메일로 보냅니다.
